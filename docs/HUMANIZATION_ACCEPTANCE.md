# QQ AI 群友｜人性化能力与数值验收

本文件是对原 Tulpa/MaiBot 需求的逐项对账。**已有代码、合成测试、真实群聊验收不能混为一谈**。

## 行为数值表

本机控制台 http://127.0.0.1:18761/ 的「行为数值表 / BEHAVIOR BALANCE」已经接入可写配置。

| 参数组 | 可编辑数值 | 实际用途 |
| --- | --- | --- |
| 社交参与 | 普通插话概率、短期接话概率、注意力窗口、冷却、每小时上限、免打扰起止 | 限制非定向参与；定向问题另行处理 |
| 发言节奏 | 连发静默、最长收集窗口、主动回复有效期 | 合并连续发言，过时插话自动放弃 |
| 对话上下文 | 最大上下文条数、最大回复长度 | 控制群内输入/输出规模 |
| 模型额度 | 单次超时、小时/日预算、调用间隔 | 避免订阅额度被无限消耗，不显示 ChatGPT 官方剩余额度 |

预设 **潜水 / 日常 / 活跃**。三个预设仅影响所列五项社交数值，其他数值继续保留；数值保存需要本人点击按钮。系统校验范围、刻度、配置版本；不能借此编辑 QQ 白名单、API/Codex 权限、模型模式或出站开关。

建议初次启用真实主动参与时先选择潜水：普通概率 1%、短期接话 18%、600 秒冷却、每小时最多 1 次。日常为 5%/42%/180 秒/4 次；活跃为 12%/55%/120 秒/6 次（只建议用在测试群）。

## “人性化”验收门槛

不追求伪装成人，只追求自然、低打扰、有边界。先在成员已知情的测试群收集 24–72 小时的**同意样本**，由人工记录：不该发话时保持沉默的比例、连发抢答与对象错误、话题跳转后过期回复、机械固定句式比例、平均回复长度、重复 QQ 消息、群成员负面反馈。

每个错误要有可复现的样本和对应修复，不能用“模型感觉像人”代替验收。尤其不得把私人群聊天记录上传公开仓库或用未经同意的内容训练画像。

**结论：基础行为和数值控制已经具备，不能称完整人性化已经交付。** 语义 Planner、语气学习、群别人格、引用/分泡与真实多日验收是明确的剩余任务。
